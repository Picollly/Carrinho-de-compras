# 🛒 Carrinho de Compras

Este projeto simula a funcionalidade principal de um e-commerce: a gestão de um carrinho de compras.  
A aplicação permite selecionar produtos, definir quantidades, calcular valores totais em tempo real e gerenciar a lista de itens adicionados.

---

## 🚀 Funcionalidades

- 🛍️ **Seleção de Produtos**  
  Menu dinâmico com diferentes categorias de produtos e preços pré-definidos.

- 💰 **Cálculo em Tempo Real**  
  Atualização automática do valor total com base na quantidade e preço unitário.

- 📋 **Gestão de Lista**  
  Adição visual de itens ao carrinho com formatação dinâmica de moeda.

- 🔄 **Limpeza de Dados**  
  Função para resetar o carrinho e zerar o faturamento total.

---

## 🧠 Destaque Técnico: Manipulação de Dados

Neste projeto, o foco foi a **extração e tratamento de dados diretamente do DOM**.

Um ponto interessante é a lógica de **Data Parsing**:

> Utilização do método `.split()` para isolar valores numéricos de strings formatadas (ex: `R$100`), permitindo realizar cálculos matemáticos com dados originalmente textuais.
